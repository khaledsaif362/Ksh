Scrip-wise Calculation

Detailed calculation for each scrip

Scrip Holding Value Allowed Buyback Value Buyback Value Max Buyback Qty Buyback Qty Remaining Qty Buy Price New Peak Buyback Margin Status
Calculation:
Holding Value = Holding Qty × Holding Price
Initial Peak = Total Holding Value × Peak %
Receivable = Total Holding Value × CFS %
Initial Available = Receivable − Initial Peak
Remaining Position = Holding Qty − Buyback Qty
New Peak = Remaining Position × Holding Price × Peak %
Peak Hit Available Fund = Initial Available + Total New Peak
Buyback Value = Buyback Qty × Buy Price
Allowed Buyback Value = Holding Value × Buyback %
Max Buyback Qty = FLOOR(Allowed Buyback Value ÷ Buy Price)
Calculated Margin = Total Buyback Value
Additional Required = MAX(Calculated Margin − Peak Hit Available Fund, 0)
